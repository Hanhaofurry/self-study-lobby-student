# 學生帳號與雲端紀錄：老師設定步驟

網站透過「你自己的 Google 試算表＋Apps Script」提供學生登入與雲端紀錄。學生名單、密碼（加密儲存）、學習紀錄都只存在你的 Google 帳號，**不會**放進 GitHub。

- 帳號：學號；第一次登入的密碼：學號。
- 第一次登入後，學生必須設定自己的新密碼（至少 6 個字、不能等於學號）。
- 學生在任何電腦或手機登入，都會看到同一份紀錄。

## 一次性設定（約 10 分鐘）

### 1. 匯入名單到試算表

1. 打開你的 Google 試算表（建議用學校 Google 帳號；若學校帳號不允許「任何人」存取網頁應用程式，改用個人 Gmail）。
2. **檔案 → 匯入 → 上傳**，選擇 `學生帳號_匯入用.xlsx`。
3. 匯入位置選「**取代試算表**」，按「匯入資料」。
4. 確認有 `Students`、`Classes`、`Records`、`Activity`、`Sessions`、`Overview` 六個工作表。
5. **共用設定改成「限制」**（只有你能開）。網站不需要試算表被共用。

### 2. 貼上後端程式

1. 在試算表選 **擴充功能 → Apps Script**。
2. 刪掉編輯器裡原本的內容，把 repo 中 `backend/Code.gs` 的全部內容貼上，按儲存。
3. 上方函式選單選 `setup`，按「執行」。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。（這是你自己寫給自己用的程式，Google 才會這樣提示。）

### 3. 發布成網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 類型選「**網頁應用程式**」。
3. 執行身分：**我**；誰可以存取：**所有人**。
4. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

### 4. 把網址接到網站

把網址填進 repo 的 `js/config.js`：

```js
export const API_URL = "https://script.google.com/macros/s/…/exec";
```

在 GitHub 網頁上編輯這個檔案並 Commit，幾分鐘後網站就會要求登入。

## 日常管理

| 想做的事 | 怎麼做 |
| --- | --- |
| 看學生練習了什麼 | `Activity` 工作表：每完成一組題目新增一列（時間、班級、座號、姓名、題組、分數、獨立完成題數、提示次數、時間、版本、反思） |
| 看每位學生總覽 | 試算表上方選單 **自學大廳 → 更新總覽**，再看 `Overview` |
| 學生忘記密碼 | 在 `Students` 選取該生那一列 → **自學大廳 → 把選取的學生密碼重設為學號**（或直接清空 `password_hash` 和 `salt`） |
| 新增／轉入學生 | 在 `Students` 新增一列：`student_id`、`name`、`class_code`、`seat`，`active` 填 TRUE，密碼欄留空 |
| 學生轉出／停用 | 把 `active` 改成 FALSE（紀錄保留） |
| 換學期、換名單 | 把新名單貼到 `Students`（舊學生可刪除或設 FALSE）；新班級加到 `Classes` |
| 只開放部分單元 | `Classes` 的 `released_units` 填單元代碼，用逗號分隔，例如 `g10-u01,g10-u02`；留空＝全部開放 |
| 改計分或提示 | `scoring_mode`：`practice`（練習）／`no-penalty`（提示不扣分）／`quiz`（小考）；`hint_max`：0–4 |
| 預設文章版本 | `default_level`：`support`（支援版）或 `standard`（標準版）；`allow_level_switch` 決定學生可否自己切換 |
| 讓所有人重新登入 | **自學大廳 → 讓所有學生重新登入** |

`Classes` 的 `course_id`：十年級 `g10-core-a`、十一年級 `g11-core-a`、十二年級 `g12-core-a`。

> 修改 `Code.gs` 之後，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不變。只改試算表內容則不需要重新部署。

## 隱私與安全

- 密碼以加鹽 SHA-256（多次雜湊）儲存，連老師也看不到學生的新密碼。
- 同一學號連續輸錯 8 次會鎖定 10 分鐘。
- 登出時會清除該台電腦上的學生紀錄副本，適合學校公用電腦。
- 試算表請保持「限制」共用；不要把名單或試算表連結放到公開的地方。
